# Broader catalogue and feedback review, October 13, 2026

This batch reviews 50 projects: 20 from the next retained feedback drafts, plus 30 metadata-gap entries sampled across years and linked destinations. Selection is deterministic within those groups; it is an editorial sample, not a representative survey.

The decisions live in `data/catalogue-reviewed-broad-october13.json`, `data/history-reviewed-broad-october13.json` and `data/feedback-reviewed-broad-october13.json`. Private preparation retains the source responses and database backup outside the repository.

## Catalogue decisions

78 accepted field observations include actual names, primary genres, build states, supported devices, creator-linked destinations and source repositories. The review reads 58 original posts and reuses dated storefront evidence. Four destination checks recover or correct specific links; HTTP success does not prove that a game runs.

- No Name Squish Game's two entries become one history anchored by the latest post. The former project URL resolves through an alias.
- War Of the Worlds becomes a separate project from the same author's FarmRise example. Explicit names and different game IDs establish that they are different projects. Both source posts remain accessible.
- Development environments are not release platforms. Snackdown's iOS release does not imply an Android or Windows build. Marble's TestFlight beta is playable, not a full release.
- Generic itch.io homepages, tools and asset references do not become Play links. Uncertain names and genres remain flagged. Known broken links remain visible as dated observations.

The catalogue retains 1,325 projects and all 1,429 source posts after the merge and split. Assigned primary genres rise from 691 to 707; known build states rise from 629 to 648. Destinations remain 610. Those changes describe better metadata coverage, not new releases or new community activity.

## Feedback decisions

20 additional summaries use 43 citations checked against current archive responses. Publication takes the reviewed total from 51 to 71. Each excerpt, author, date and parent project is checked; the prose and labels are individually reviewed. No additional Jev calls are made for this batch.

Duplicate comments are not independent players. A reported hosting outage retains its follow-up acknowledgment that the creator fixed it. Someone unable to launch the game is not classified as having played. Missing sentiment and context remain unclassified. The two separated games receive separate summaries, and the Squish Game review combines only comments belonging to its verified history.

The transaction is rehearsed against a fresh production export, then rebased before publication. It preserves all 17 uploaded previews, 51 earlier reviews, previous destination observations, administrator overrides, guest feedback, ratings, favorites, questionnaires and private responses. Guards reject concurrent source, contribution or editorial changes.

After the UTC reset, production reads confirm 1,325 projects, 71 published reviews and 17 uploaded previews. A fresh production export matches all rehearsed project, source, accepted-fact, review, alias and override rows. Seventeen protected tables and all earlier link observations are preserved. Anonymous usage totals can grow independently while the batch runs; the batch never writes those tables.
